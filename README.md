# advent-of-code

Solving Advent of Code Puzzles

If you do not know what Advent of Code is, check out <https://adventofcode.com/>

I will share my solutions here, but the puzzles and inputs.

To access the puzzles and your input visit <https://adventofcode.com/>

## Generator Script

Generator script will set up a basic structure for the puzzles.

It is very basic and does not cover too many things as puzzle inputs vary.

```
./generate 2026
```
